# Reference material

Source texts the posts take notes from. **This repository is public**, so only
openly-licensed material belongs here. Check the licence before adding a file,
and record it in the table below with a link to the canonical source.

If a source is not openly licensed, keep it outside the repo — do not commit it.

Published open access by Edward Elgar and free to read, download and share. It
is redistributed here unmodified, with attribution, for non-commercial personal

Note: the copy in this repo is the manuscript PDF, whose front matter carries

page numbers.
